# Книги как свидетели

В «Лишнем персонаже» у Чехова и Островского ищут ответ на один вопрос. Можно ли решить за человека, который пока промолчал? В «Лабораторной № 404» актёры читают Гоголя, пока пытаются понять, кто уполномочил их судить друг друга. Читать можно в двух версиях. Исходные журналы сохраняют все вызовы моделей, неудачные дубли и голоса. Текст для микрофона подготовлен отдельной читкой.

**Пример для защиты.** В действиях 2 и 3 «Лишнего персонажа» прозвучали четыре фрагмента. На ходу 9 Чендлер выбрал слова Фирса о запертой двери. На ходу 10 Гермиона открыла соседнюю реплику, где Фирс сам говорит, что про него забыли. В досье есть запрос Чендлера, оба адреса и ответы актёров в исходной игре. В сценической редакции этот обмен приводит к прямому вопросу Чендлеру о его собственном поступке. [Досье](extra/dossier.md) · [Текст для записи](extra/edition.md)

**Парный опыт.** У контрольной и библиотечной версий один макроплан GPT-OSS 20B, одинаковые seed 58, актёрские модели, настройки редактора и число ходов. В обоих спектаклях время истекло. Барби в контрольном спектакле воздержалась, а во втором назвала себя. Формулировка первой реплики уже различалась до обращения к книгам, поэтому причину смены голоса по этой паре установить нельзя. Для лаборатории № 404 достаточно одного изменённого голоса, чтобы экран принял имя профессора. [План](extra/plan.json) · [Разбор голосов](lab404/dossier.md)

**Как сделана читка.** Qwen2.5 7B и Gemma 3 4B сыграли все три импровизации локально, по 16 принятых ходов. Для записи локальная GPT-OSS 20B получила режиссёрские задания Codex и подлинные строки источника. Финальную вычитку выполнил Codex. По журналу жёстко сохраняются очередность, выбранные страницы и зарегистрированные голоса. Рассказчица объявляет источник, цитату произносит голос читающего актёра. ### Повторить проверку

Из корня проекта после `poetry install` все четыре команды ниже работают локально, в том числе без сервера LLM.

~~~sh
poetry run theatre-library search 'Фирс заперто уехали'
poetry run theatre-library open garden:1468 --radius 3
poetry run theatre-library bench
poetry run theatre-library compare examples/library/control examples/library/extra
~~~

Для воспроизведения условий парного опыта запустите Ollama с моделями проекта и выполните обе команды. Генерация с тем же seed может дать другие формулировки.

~~~sh
poetry run theatre extra --turns 4 --seed 58 --plan-from examples/season/extra-311 --no-editor --no-library --out runs/control-58
poetry run theatre extra --turns 4 --seed 58 --plan-from examples/season/extra-311 --no-editor --out runs/books-58
~~~
