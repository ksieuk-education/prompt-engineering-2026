# Полные тексты для театральной библиотеки

Три файла TEI P5 воспроизведены из Русского драматического корпуса DraCor. В заголовке каждого XML указаны издание, ответственные за оцифровку и лицензия CC0 1.0. Контрольные суммы SHA-256 и редакция корпуса зафиксированы в каталоге. [RusDraCor](https://dracor.org/rus) · [Замороженная редакция](https://github.com/dracor-org/rusdracor/tree/cb06b3a211cc36ed0806c9ae85a94ede5da99557) · [Лицензия](https://creativecommons.org/publicdomain/zero/1.0/) · [Каталог](catalog.json)

| Ключ | Произведение | Действий | Фрагментов |
| --- | --- | ---: | ---: |
| `garden` | А. П. Чехов, «Вишнёвый сад» | 4 | 1 479 |
| `inspector` | Н. В. Гоголь, «Ревизор» | 5 | 1 605 |
| `dowry` | А. Н. Островский, «Бесприданница» | 4 | 1 782 |

Например, `garden:1468` — фрагмент № 1468 в индексированном тексте Чехова. Ключ открывает реплику с именем говорящего и местом в действии. У каждой карточки есть ссылка на строки XML этой редакции. Длинная реплика делится на части, которым может соответствовать один XML-абзац. При показе текста программа нормализует пробелы и Unicode. При сокращении открытого предложения добавляет видимое многоточие.

Литературные задачи для сцен и 18 вопросов проверки составлены для этой лабораторной. В разметке положительных примеров указаны подходящие диапазоны строк XML. Поисковик не получает эти диапазоны и ключ ожидаемой книги при оценке. [Вопросы](queries.json) · [Публикация о DraCor, Fischer et al., 2019](https://doi.org/10.5281/zenodo.4284002)
